📚 Online Book Store SQL Project

This project is a complete SQL-based analysis of an Online Book Store Database using PostgreSQL.
The database was created from CSV files and includes tables for Books, Customers, and Orders.

🚀 Project Features
Database creation using SQL
Table relationships with Primary & Foreign Keys
CSV file data import using COPY
Basic SQL Queries
Advanced SQL Analysis Queries
Sales and Revenue Analysis
Customer Purchase Insights
Inventory & Stock Analysis
